Manual de uso

Guía completa para administrar el portal DIGSA

📌 Este manual es solo para administradores. Aquí encontrás todo lo que necesitás saber para gestionar inversores, propiedades, aportes y liquidaciones desde el portal.

1. Inversores

1

Crear un nuevo inversor

Ir a Admin → Inversores → + Nuevo inversor. Completar nombre, apellido, email y contraseña. El email será su usuario para ingresar al portal.

💡 La contraseña puede cambiarse en cualquier momento desde Editar inversor. El inversor puede ver sus propias propiedades, aportes, documentos y liquidaciones.
2

Editar datos de un inversor

Hacé clic en Editar en la fila del inversor. Podés cambiar email, teléfono y contraseña. Si dejás la contraseña vacía, no se modifica.

2. Propiedades

1

Agregar una propiedad nueva

Ir a Admin → Propiedades → + Nueva propiedad. Completar nombre, dirección, estado (en obra / disponible / reservado / vendido), tipo (flipping / renta / mixto), precio de compra y gastos.

💡 Podés agregar los inversores participantes directamente desde el modal usando el botón "+ Agregar". Ingresá el monto invertido y el porcentaje de participación de cada uno.
2

Estados de una propiedad

En obra → la propiedad está en proceso de reforma. Disponible → lista para vender. Reservado → hay comprador interesado. Vendido → liquidado.

3. Aportes y retiros

1

Registrar un aporte

Ir a Admin → Aportes → + Registrar aporte. Seleccionar el inversor, ingresar el monto en USD, el tipo de cambio USD/EUR y la fecha. Si el aporte va a una propiedad específica, seleccionarla.

💡 Al registrar un aporte, el sistema genera automáticamente el reporte actualizado del inversor y lo notifica.
2

Registrar un retiro

Mismo proceso que el aporte, pero cambiando el tipo a Retiro. El monto se resta del capital del inversor. Aparecerá en negativo en el historial.

4. Liquidar un piso

1

Generar la liquidación

Ir a Admin → Liquidar piso. Seleccionar la propiedad, ingresar el precio final de venta en EUR, la fecha, el fee de éxito (por defecto 15%) y los alquileres acumulados si los hubiera.

2

Cómo se calcula la liquidación

El sistema calcula automáticamente para cada inversor:

Ingresos totales = Precio venta + Alquileres
Utilidad bruta = (Ingresos totales − Inversión total) × % participación
Fee de éxito = Utilidad bruta × 15%
Impuestos = (Utilidad bruta − Fee) × 25%
Liquidación = Aporte + Utilidad bruta − Fee − Impuestos
💡 Al generar la liquidación, el sistema sube automáticamente el PDF al portal de cada inversor y les envía una notificación.
3

Destino de los fondos

En el campo "Destino de los fondos" podés indicar a qué próxima inversión se destinará el dinero liquidado (por ejemplo: "Lagasca 58, Ayala 78"). Esto aparece en el PDF de cada inversor.

5. Reportes automáticos

✓

¿Cuándo se genera un reporte?

El sistema genera y sube automáticamente un reporte actualizado para el inversor afectado cada vez que:

  • Se registra un aporte o retiro nuevo
  • Se genera una liquidación de un piso
💡 No necesitás hacer nada. El reporte aparece automáticamente en la sección "Documentos" del inversor.

6. Análisis y seguimiento

★

Panel de Análisis

En el menú superior encontrás la sección Análisis. Ahí podés ver de un vistazo el estado de todos los inversores: capital invertido, rentabilidad, pisos activos y finalizados. Hay gráficos por inversor y por piso para tener una visión rápida del portfolio completo.

7. Referencia rápida

📊 Métricas clave
  • Capital invertido = suma de aportes en EUR
  • Rentabilidad = (retorno − aporte) / aporte
  • Fee de éxito = 15% de la utilidad bruta positiva
  • Impuestos = 25% de (utilidad − fee)
⚡ Acciones frecuentes
  • Nuevo inversor → Admin → Inversores
  • Registrar aporte → Admin → Aportes
  • Liquidar piso → Admin → Liquidar piso
  • Ver análisis → menú Análisis
🔔 Notificaciones automáticas
  • Nuevo aporte registrado
  • Liquidación disponible
  • Reporte actualizado
📁 Documentos
  • Subir PDF manual → Admin → Subir documentos
  • Reportes automáticos → se generan solos
  • Liquidaciones PDF → se generan al liquidar
