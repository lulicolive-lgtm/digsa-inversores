Manual de administración

Guía completa para gestionar el portal DIGSA · Solo para administradores

⚡ Automatización activa: Al registrar un aporte o liquidar un piso, el sistema genera automáticamente el reporte PDF del inversor afectado y se lo notifica. No necesitás hacer nada manual.
1
Inversores
👤

Crear un inversor

Admin → Inversores → + Nuevo inversor. Completar nombre, apellido, email y contraseña. El email es el usuario para ingresar al portal. Para editar datos o cambiar contraseña, usar el botón Editar.

💡 Si dejás la contraseña vacía al editar, no se modifica.
2
Propiedades
🏠

Agregar una propiedad

Admin → Propiedades → + Nueva propiedad. Completar nombre, dirección, estado, tipo y precios. Podés agregar los inversores y sus porcentajes de participación directamente desde el mismo modal.

💡 Estados: En obra = reforma en proceso · Disponible = lista para vender · Reservado = comprador interesado · Vendido = liquidado
3
Aportes y retiros
💸

Registrar un aporte o retiro

Admin → Aportes → + Registrar aporte. Seleccioná el inversor, el monto en USD, el tipo de cambio USD/EUR y la fecha. Para retiros, cambiá el tipo a "Retiro".

💡 Al guardar, el sistema genera automáticamente el reporte actualizado del inversor y le envía una notificación.
4
Liquidar un piso
⚡

Cómo generar una liquidación

Admin → Liquidar piso. Seleccioná la propiedad, ingresá el precio de venta final en EUR, la fecha, el fee de éxito (default 15%) y los alquileres acumulados si los hay.

💡 El sistema genera el PDF de liquidación para CADA inversor automáticamente, lo sube al portal y les notifica.
🔄

Reinversión automática

En la sección "Destino de los fondos" aparecen todos los pisos activos con checkboxes. Seleccioná los pisos donde querés reinvertir el dinero de la liquidación.

El sistema distribuye el dinero de cada inversor proporcionalmente al precio de compra de cada piso destino. Por ejemplo si hay dos pisos, uno de €500k y otro de €250k, el primero recibe el doble.

💡 Si no seleccionás ningún piso destino, el dinero queda registrado como "pendiente de asignación" en el historial del inversor. Podés asignarlo después desde Admin → Aportes.
🧮

Fórmula de cálculo

Ingresos totales = Precio venta + Alquileres
Utilidad bruta por inversor = (Ingresos − Inversión total) × % participación
Fee de éxito = Utilidad bruta × 15% (si positivo)
Impuestos = (Utilidad bruta − Fee) × 25%
LIQUIDACIÓN = Aporte + Utilidad bruta − Fee − Impuestos

  • Sube PDF al portal de cada inversor
  • Genera reportes actualizados

  • Marca el piso como vendido
  • Reinvierte proporcionalmente en pisos destino
  • Registra aportes y participaciones nuevas
  • Notifica reinversión a cada inversor
